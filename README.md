# odin-recipes-Kaizuka
This project is part of The Odin Project full-stack curriculum. It is a simple static website that displays a collection of recipes, built using only HTML.

## About
The site consists of a main page that links to individual recipe page. Each recipe page contains the recipe title, an image, ingredients list, and step-by-step instructions.

## Pages
- **index.html** - Main page with link to all recipes
- **recipes/salad.html** - Watermelon Summer Salad
- **recipes/pasta.html** - Basic Homemade Pasta
- **recipes/burger.html** - Bigger Better Big Arch Burger
